# African Family Connect

African Family Connect is a web application designed to provide African families with a digital platform for accessing useful family, parenting, and community resources.

## Project Overview

The project explores how modern web technologies can be used to create an accessible and responsive platform for African families.

The application was initially developed with the assistance of Lovable. I then integrated the project with GitHub and worked with the codebase locally using Git, PowerShell, and Visual Studio Code.

This project is also part of my practical DevOps learning journey, with emphasis on version control, application configuration, testing, deployment, and CI/CD.

## My Role

My work on this project includes:

- Defining the application requirements and structure
- Using Lovable to generate the initial application
- Reviewing and modifying the generated code
- Connecting the project to GitHub
- Cloning and managing the repository locally
- Using Git for version control
- Working with the project through Visual Studio Code
- Testing the application locally
- Preparing the application for deployment
- Building a CI/CD workflow for automated validation and deployment
